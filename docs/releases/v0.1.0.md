# v0.1.0

Initial public release of AIVoice Agent.

## Highlights
- Local-first voice agent built on LiveKit
- OpenAI-compatible Kyutai STT and TTS integration
- Ollama local LLM support with `gemma3n:latest`
- Public-repo cleanup with install metadata, license, changelog, and safe env template

## Verified runtime pieces
- LiveKit server endpoint
- Kyutai STT health endpoint
- Kyutai TTS health endpoint
- Ollama API and `gemma3n:latest` model availability

## Notes
- `.env.local` is intentionally excluded from git
- `.env.local.example` is the committed setup template
- `tts.py` was removed as stale dead code in favor of the active `openai.TTS(...)` path in `agent.py`
